Team Engineering Project / 2026

Autonomous Drone for Marine Pollution Mapping

Developed an autonomous drone prototype capable of detecting and mapping marine pollution. Integrated a LiDAR TF-Luna infrared sensor utilizing the Time-of-Flight (ToF) principle to detect water surface irregularities, alongside two HC-SR04 ultrasound sensors for 2D spatial positioning. Managed hardware data collection through an Arduino microcontroller. Processed the telemetry data in Python, implementing a Kalman filter to smooth sensor noise and generating a real-time 2D grid map of the detected waste using Tkinter.
